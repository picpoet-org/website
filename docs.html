Documentation

把媒体库交给 Picpoet。

从安装到第一次批量打标，这里提供一条清晰、可回滚的使用路径。

安装配置常用命令安全写回

安装

命令行版本要求 Node.js 20.12 或更高版本。

npm install
npm run build

配置视觉模型

Picpoet 兼容 OpenAI-compatible API，也可以连接本地模型服务。创建配置文件或使用环境变量提供模型地址和 API key。

{ "baseURL": "http://localhost:11434/v1", "model": "llava:13b", "language": "zh" }

常用命令

npm start -- tag ./photos npm start -- scan ./photos npm start -- read ./photos/photo.jpg npm start -- config

首次运行建议使用 --dry-run 观察结果，确认模型输出后再写回文件。

安全写回

默认模式会复制源文件并在文件名后追加 _tagged，不会覆盖原始媒体。需要直接写回时，请显式选择 overwrite 模式。
