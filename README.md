# Picpoet website

Picpoet 的公开网站，集中维护产品使用说明、定价信息和下载入口。

## 本地预览

要求 Python 3：

```bash
npm run dev
```

打开 <http://localhost:8080>。

## 页面

- `/index.html`：产品首页
- `/docs.html`：使用说明
- `/pricing.html`：定价
- `/downloads.html`：下载资源

下载链接默认指向 `picpoet-org/desktop-app` 的 GitHub Releases，发布桌面应用后即可使用。
